# Product Requirements Document (PRD) — Picsart Academy Library

**Նախագիծ / Project:** Project 9 — Picsart Academy Library  
**Կարգավիճակ / Status:** MVP Implemented & Verified  
**Լեզուներ / Languages:** Հայերեն (`HY`) և English (`EN`)

---

## 1. Խնդիրը (Problem Statement)
Դասախոսները օգտակար նյութերը (գրքեր, հոդվածներ, տեսանյութեր, հղումներ) կիսում են տարբեր տեղերում՝ Slack-ում, Classroom-ում, Google Drive-ում և գրասենյակի ֆիզիկական գրապահարանում։ Մի քանի շաբաթ անց.
- հղումները կորչում են զրույցների մեջ,
- տարբեր խմբերի ուսանողները չեն տեսնում մյուս խմբերի լավ նյութերը,
- ոչ ոք չգիտի՝ գրասենյակի որ ֆիզիկական գիրքն է ազատ կամ ում մոտ է գտնվում։

## 2. Նպատակը և Հաջողության Չափանիշները (Goals & Success Metrics)
Ստեղծել մեկ միասնական, արագ և չափազանց պարզ գրադարանային կատալոգ ամբողջ Ակադեմիայի համար։
- **Որոնման արագություն.** ցանկացած նյութ գտնել `< 3 վայրկյանում` full-text որոնմամբ։
- **Պարզություն (Illusion of Simplicity).** առաջին անգամ մուտք գործող ուսանողը առանց հրահանգների հասկանում է ինչպես որոնել, ֆիլտրել և վերցնել գիրք։
- **Օրինականություն.** 0 հեղինակային ֆայլերի հոսթինգ՝ միայն օրինական արտաքին հղումներ։

## 3. Օգտատերերի Դերերը (User Personas & Roles)

| Դեր (Role) | Նկարագրություն | Հիմնական գործողություններ |
|---|---|---|
| **Student (Ուսանող)** | Սովորում է կոնկրետ խմբում (`JS-24`, `PY-24`) | Որոնել, ֆիլտրել, դիտել խմբի հավաքածուները, ստանալ Skill Map առաջարկներ, վերցնել/վերադարձնել ֆիզիկական գիրք |
| **Lecturer (Դասախոս)** | Դասավանդում է դասընթաց, կազմում է նյութեր | Ավելացնել/խմբագրել/ջնջել **իր** նյութերը, ստեղծել խմբային հավաքածուներ, սինխրոնիզացնել Reel դասերը |
| **Admin (Ադմին)** | Կառավարում է ամբողջ գրադարանը և գրասենյակի գրքերը | Լիարժեք CRUD ցանկացած նյութի/հավաքածուի վրա, վերադարձնել ցանկացածի վերցրած գիրքը Depot-ում |

## 4. Ֆունկցիոնալ Պահանջներ (Functional Requirements & User Stories)

### FR-1. Միասնական կատալոգ և CRUD իրավասություններով
- **US-1.1:** Որպես դասախոս՝ ուզում եմ ավելացնել նոր նյութ (գիրք, հոդված, տեսանյութ, ձայնագրություն)՝ նշելով դասընթացը, թեման, մակարդակը և թեգերը։
- **US-1.2:** Որպես համակարգ՝ պետք է ստուգեմ իրավասությունները backend-ում (`403 Forbidden`), որպեսզի ուսանողը չկարողանա փոփոխել կատալոգը, իսկ դասախոսը կարողանա խմբագրել միայն իր ավելացրածը։
- **US-1.3:** Որպես համակարգ՝ պետք է արգելեմ ոչ օրինական հղումները (օր.՝ `.torrent` կամ ծովահենային կայքեր)։

### FR-2. Full-Text Որոնում և Ֆիլտրում
- **US-2.1:** Որպես ուսանող՝ ուզում եմ տպել բառ (օր.՝ `promises` կամ `sql`) և ակնթարթորեն ստանալ ռելևանտությամբ դասավորված արդյունքներ (SQLite FTS5 + BM25 ranking)։
- **US-2.2:** Որպես ուսանող՝ ուզում եմ ֆիլտրել ըստ տեսակի, դասընթացի, թեմայի, մակարդակի և `#tag`-երի։

### FR-3. Link Previews
- **US-3.1:** Որպես դասախոս՝ նյութի URL-ը տեղադրելիս ուզում եմ մեկ կոճակով ավտոմատ լրացնել վերնագիրը, նկարագրությունը և շապիկի նկարը (Open Graph metadata)։

### FR-4. Խմբային Հավաքածուներ (Group Collections)
- **US-4.1:** Որպես դասախոս՝ ուզում եմ ստեղծել թեմատիկ ցուցակ իմ խմբի համար (`JS-24 Week 4–6 Essentials`) և ավելացնել/հեռացնել նյութեր։

### FR-5. Ինտեգրացիաներ (Simulated / Modular)
- **Reel:** Ավտոմատ կամ մեկ սեղմումով ներմուծել դասերի նոր տեսագրությունները (idempotent sync՝ առանց կրկնօրինակների)։
- **Skill Map:** Ուսանողի բացթողումների (`skill_gaps`) հիման վրա «Քեզ համար» բաժնում ցուցադրել կոնկրետ առաջարկվող նյութեր։
- **Depot:** Ցուցադրել գրասենյակի ֆիզիկական գրքերի դարակը, ազատ օրինակների քանակը, ով է վերցրել, և թույլ տալ 14 օրով վերցնել/վերադարձնել։

## 5. UX Սկզբունք՝ «Illusion of Simplicity»
Համակարգը նախագծված է այնպես, որ բարդ հնարավորությունները չծանրաբեռնեն օգտատիրոջը.
1. **Մեկ առաջնային գործողություն ամեն էկրանում.** գլխավոր էջի կենտրոնում միայն որոնման դաշտն է ու տեսակի արագ կոճակները։
2. **Progressive Disclosure (աստիճանական բացահայտում).** երկրորդական ֆիլտրերը (`Course`, `Topic`, `Level`, `Tags`, `Group By`) թաքնված են մաքուր **«Ֆիլտրեր»** կոճակի տակ և բացվում են միայն երբ օգտատերը ցանկանում է խորը ֆիլտրել։
3. **Գունային կոդավորում.** դեղին = Գրքեր, փիրուզագույն = Հոդվածներ, մանուշակագույն = Տեսանյութեր / Reel դասեր — օգտատերը առանց կարդալու վայրկյանում տարբերում է նյութի տեսակը։
4. **Ստեղնաշարի արագ հասանելիություն.** `Ctrl + K` կամ `/` անմիջապես ֆոկուսավորում է որոնումը։

## 6. Ոչ ֆունկցիոնալ պահանջներ (Non-Functional Requirements)
- **Արագագործություն.** SQLite ինդեքսներ, FTS5, `facets` և Link Preview քեշավորում, React code splitting (`React.lazy`) և `AbortController`։
- **Անվտանգություն.** SSRF պաշտպանություն Link Preview-ում (արգելված են `localhost`/մասնավոր IP-ները), role-based access control backend-ում, JSON payload սահմանափակում (`100kb`)։
- **Հասանելիություն.** Dark & Light ռեժիմներ, Հայերեն (`Noto Sans Armenian`) և English լիարժեք աջակցություն։

## 7. Շրջանակից դուրս (Out of Scope for MVP)
- Իրական OAuth2/SSO մուտք (MVP-ում օգտագործվում է Role Switcher՝ բոլոր դերերը արագ ցուցադրելու համար)։
- Հեղինակային PDF/EPUB ֆայլերի պահպանում սերվերում։
- Էլ. փոստի/Slack-ի ավտոմատ հիշեցումներ ուշացած գրքերի համար։
